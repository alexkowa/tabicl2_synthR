# tabicl2synthr 0.0.1

* Initial release.
* `tabicl_synthesize()`: generate a synthetic data set from an input data set
  via TabICLv2 unsupervised autoregressive sampling.
* `tabicl_impute()`: fill missing values by conditioning on observed columns.
* `tabicl_score_samples()`: score rows by estimated typicality (outlierness).
